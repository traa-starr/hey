# Planning input (rough, not final)

The files in this folder came from planning chats in the Hey You project. They are **starting ideas, not specs**.

How to use them:
- Treat them as context and direction to expand on, question and improve. They are not a task list to copy.
- Do your own planning. Check what already exists in the code first; some of this may be built already (for example, spaced look backs on home and `recall` cards in lessons) or may clash with `docs/SPEC.md`, `docs/growth/PLAN.md` or `CLAUDE.md`.
- If something here conflicts with the existing docs, the existing docs win until the person decides otherwise. Note the conflict instead of picking quietly.
- Batch numbers and order are suggestions only.

Files:
- `roadmap.md`: rough direction for lessons, practice rhythm and clarity.
- `lesson-template.md`: a proposed shape for lessons.
