# Lesson template (proposal)

Idea: every lesson has these five beats. If one can't be filled, the lesson isn't ready.

1. **Notice.** A real, specific moment (e.g. dropping coffee and thinking "of course, i ruin everything"). Never a vague idea.
2. **Why it works.** One sentence of mechanism, plus a "where this comes from" tap showing the real source (distanced self-talk / Kross, defusion / ACT, self-compassion / Neff).
3. **Try it now.** On the person's own sentence, chosen from tappable options. No blank text boxes.
4. **Take it with you.** A tiny "when ___ happens, i'll ___" plan (implementation intention).
5. **Check back.** Next open, dawn asks "did you try it?": tried it / forgot / felt weird. All three are fine. "Felt weird" gets a gentle follow-up.

## Slop test
If the lesson would still make sense as a fortune cookie, it isn't done.

## Voice
Short bubbles, real speech, exploring not correcting, never imply the person is doing something wrong.
