# Roadmap direction: lessons, practice rhythm, clarity

Principle: progression means needing the app less. Measure use out in life, not taps. No streaks, nothing resets.

## Batch 1: lesson template + one pilot lesson
- Agree on a lesson shape (see `lesson-template.md`)
- Rewrite ONE lesson to it as a pilot (the words are written in the planning chat, then dropped in)
- Review the pilot at phone size

## Batch 2: take-it-with-you + check-back
- If-then plan step at the end of lessons
- Check-back prompt on next open (tried it / forgot / felt weird)

## Batch 3: skill stages + spaced resurfacing
- Per-technique stages: learned, tried, used out there, automatic (driven by check-backs)
- Resurface at about 1, 3, 7, 14 days as a 1-minute rep (check against the existing review plugin first)
- Path level 2 unlocks after USING level 1, not just reading it
- Daily 2-minute rep + weekly look-back; "welcome back" after gaps

## Batch 4: book redesign (mockup first, then build)
- Direction idea: chapters and pages, with technique cards as the pages
- Table of contents, "you are here" bookmark, the person's own example sentence, visible stage

## Batch 5: clarity (assume the person has no idea what they're looking at)
- First-run tour by dawn, skippable, replayable from settings
- One plain line at the top of every screen saying what it is and what to do
- Practice tab formulas: name + frame only, details one tap away
- A first-timer greeting (home may say "thank you for coming back" on a true first visit); friendlier empty states on the you tab
- (Dropped: renaming "the book" to "your book". CLAUDE.md deliberately keeps labels without "your".)

## Batch 6: stranger test
- Hand the phone to someone new, say nothing, log every pause; fix the list
