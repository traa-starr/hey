# Synthesis kit

Everything needed to turn five sessions into decisions. The study hasn't run yet, so nothing here is a finding. Fill it in as you go, and keep observations ("P3 tapped 'learn' twice") separate from interpretations ("the tab names are unclear").

## 1. Note sheet (one per participant)

Copy this block for P1 to P5. Write what happened, not what you think it means. Quotes go in quotation marks, exactly as said.

```
P_ · date · phone (iOS/Android) · text size / screen reader · uses wellbeing apps (y/n)

first open
- [time] observation …
- "quote"

task 1 voice check   finished: y / with help / n   time: _
- …
task 2 first lesson  finished: y / with help / n   time: _
- …
task 3 loud moment   finished: y / with help / n   path taken: _
- …
task 4 your book     finished: y / with help / n
- …

reaction answers
- shared-phone worry: …
- talked down to / rushed: …
- reason to come back: …
- one word: …

follow-up (week later)
- opened again: …   why: …
- came to mind in a real moment: …
- annoyed by: …
```

## 2. Tags

Tag each observation with one area and one kind. Keep the list short, and add a tag only when three or more notes need it.

| area | kind |
| --- | --- |
| `welcome` `home` `learn` `lesson` `check` `map` `catch` `answer` `breathe` `book` `settings` `dawn` `motion` `copy` | `confusion` `discomfort` `delight` `value` `pull` `access` `privacy` `bug` |

Example: *P2 laughed at dawn's "nice work" and said "a bit much"* → `dawn` · `discomfort`.

## 3. Affinity themes

1. Put every tagged note on its own card (a sticky note, or a row in a sheet).
2. Group cards bottom-up, by what they share, not by screen. Name each group with a sentence a participant could have said, e.g. "i wasn't sure if i had to type something real".
3. A theme needs at least two participants. Note how many: "4 of 5".
4. Check each theme against the stance (CLAUDE.md): does it point at something that feels judging, revealing, or pushy? Those go first, whatever their count.

## 4. Deciding what to change

| insight (observed, with count) | opportunity | impact | effort | stance test it touches |
| --- | --- | --- | --- | --- |
| | | high / med / low | high / med / low | 1 to 6 |

Rules of thumb:
- Anything that made someone feel judged, or worried about a shared phone, is fixed before anything else, even if only one person hit it.
- Confusion seen in 3 or more of 5 people: fix now. In 1 or 2: watch in the next round.
- Feature requests are noted, never built straight from one session. Check them against the v1 scope first.

## 5. Report template

```
## in short

## what we still don't know
- …

## limits
five people, recruited through friends of friends; one session each; self-chosen inner-voice lines, so comfort may read higher than in real moments.
```

## 6. Privacy for notes

Use P numbers only, never names. Don't write down inner-voice lines a participant typed unless they say it's fine. Delete recordings within 30 days, as promised in the consent.
